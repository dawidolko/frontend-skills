Skills by technology

A skill is a short instruction for a coding agent, in the open Agent Skills format. Only the skills that match your project's stack are installed; each one names the rules it teaches.

Foundations

  • Native forms and validation

    fe-forms

    Builds and reviews HTML forms that work natively - the right input types and inputmode, autocomplete tokens, constraint validation and custom messages, select placeholders, file inputs, and submission through the form's submit event. Accessibility of forms is in fe-a11y-forms.

    Installed when the project uses: every web project9 rules954 tokens on use

  • HTML documents and semantics

    fe-html

    Writes and reviews HTML documents and templates (plain HTML, JSX, Vue, Svelte, Astro, Angular) with valid structure, semantic elements, landmarks, headings, images and buttons that work for everyone.

    Installed when the project uses: every web project6 rules869 tokens on use

  • JavaScript in the browser

    fe-javascript

    Writes and reviews browser JavaScript (plain scripts, modules, framework script blocks) - equality, declarations, async and fetch errors, DOM events, assets through the bundler - so it fails loudly, stays fast and keeps working when moved.

    Installed when the project uses: every web project13 rules1070 tokens on use

  • Responsive design

    fe-responsive

    Makes pages and components work from 320 CSS px phones to wide screens and at 400% zoom - viewport meta, fluid type and space, content breakpoints and container queries, no fixed wide boxes, dvh units, touch targets, no hover-only content, orientation and print.

    Installed when the project uses: every web project9 rules1080 tokens on use

  • TypeScript

    fe-typescript

    Writes and reviews TypeScript for front-end apps (TypeScript 7, React, Vue, Svelte, Angular, Astro) - strict config, no any, types checked at the boundaries (API, storage, forms), narrowing instead of casts, a tsconfig that builds on 6 and 7.

    Installed when the project uses: typescript6 rules1016 tokens on use

Styling

  • CSS architecture and tokens

    fe-css-architecture

    Organises and reviews stylesheets (CSS, SCSS, Less, component styles) around the project's own tokens, helpers and icon set - cascade layers, specificity, rem sizing, unitless line-height, z-index scale, no magic numbers or hard-coded asset paths.

    Installed when the project uses: every web project11 rules1053 tokens on use

  • CSS layout

    fe-css-layout

    Builds and reviews page and component layout in CSS with grid, flexbox, gap, container queries and logical properties, with no float columns, no fixed heights on text and no magic offsets.

    Installed when the project uses: every web project6 rules879 tokens on use

  • Modern CSS features

    fe-css-modern

    Uses current CSS features where they replace JavaScript or preprocessor work - native nesting, :has(), @scope, color-mix() and oklch, light-dark(), @starting-style, @property, text-wrap, anchor positioning - each with its Baseline status and a fallback.

    Installed when the project uses: every web project4 rules839 tokens on use

  • Icons

    fe-icons

    Uses and builds icons the way the project does - one icon set generated by the build from a folder of SVG files (sprite, icon classes or an Icon component per framework), currentColor sizing, decorative vs meaningful icons - and never a hard-coded icon file path.

    Installed when the project uses: every web project4 rules968 tokens on use

  • Motion and animation

    fe-motion

    Adds smooth, safe motion - transitions and keyframes on transform and opacity, prefers-reduced-motion, pause controls for auto-playing content, View Transitions and scroll-driven animations with feature checks, @starting-style for entry effects, and motion libraries set for reduced motion.

    Installed when the project uses: every web project4 rules838 tokens on use

  • Sass (SCSS)

    fe-sass

    Writes and reviews Sass (SCSS) for Dart Sass - the module system with @use and @forward, sass:math and sass:color, division, placeholders, the project's px-to-rem helper - and says when plain CSS now does the job.

    Installed when the project uses: sass9 rules1016 tokens on use

  • Tailwind CSS

    fe-tailwind

    Writes and reviews Tailwind CSS 4 code - CSS-first setup with @import and @theme, complete class names, tokens instead of arbitrary values, conflict-free class lists, sr-only labels, focus and reduced-motion variants.

    Installed when the project uses: tailwind10 rules1097 tokens on use

Frameworks

  • Angular components

    fe-angular

    Writes and reviews Angular 22 components, templates and services - signals, built-in control flow, zoneless and OnPush defaults, SSR and hydration, NgOptimizedImage, router accessibility, DomSanitizer - for fast, accessible apps.

    Installed when the project uses: angular9 rules1152 tokens on use

  • Astro sites and islands

    fe-astro

    Writes and reviews Astro 7 sites - islands and client directives, server islands, processed scripts, astro:assets images, content collections and environment variables - so pages ship little JavaScript and stay safe.

    Installed when the project uses: astro7 rules920 tokens on use

  • Data fetching

    fe-data-fetching

    Loads and changes server data in front-end apps - framework loaders, TanStack Query, SWR, Nuxt useFetch, Angular httpResource - with correct cache keys, one stable client, loading and error states, race-free effects and invalidation after mutations.

    Installed when the project uses: react, vue, svelte, angular, next, nuxt8 rules876 tokens on use

  • Next.js App Router

    fe-nextjs

    Writes and reviews Next.js 16 App Router code - Server and Client Components, async params, Server Actions, caching, metadata, next/image, next/font and environment variables - so routes stay fast, safe and correct.

    Installed when the project uses: next9 rules1053 tokens on use

  • Nuxt apps

    fe-nuxt

    Writes and reviews Nuxt 4 apps - useFetch and useAsyncData vs $fetch, keys, per-request state, server-safe setup, runtime config, route announcements - so pages render on the server without leaks, double requests or hydration errors.

    Installed when the project uses: nuxt10 rules1136 tokens on use

  • React components

    fe-react

    Writes and reviews React 19 components (also inside Next.js, Vite or React Router apps) - keys, state, effects, events, refs, forms with actions, memoization and React Compiler - so they stay correct, accessible and fast.

    Installed when the project uses: react5 rules794 tokens on use

  • State and stores

    fe-state

    Decides where front-end state lives and writes stores that stay correct - component state, URL, context, Pinia, Zustand, Redux Toolkit, Svelte runes, Angular signals - with stable selectors and no server data copied into stores.

    Installed when the project uses: react, vue, svelte, angular6 rules888 tokens on use

  • Svelte components

    fe-svelte

    Writes and reviews Svelte 5 components in runes mode - $state, $derived, $effect, $props, snippets, event attributes, keyed each blocks - and moves Svelte 4 syntax forward, so components stay reactive, correct and accessible.

    Installed when the project uses: svelte8 rules963 tokens on use

  • SvelteKit apps

    fe-sveltekit

    Builds and reviews SvelteKit 3 apps (and Kit 2 projects on the way up) - routes, load functions, form actions with progressive enhancement, page titles, server-only state and rendering options - so pages work before JavaScript, load without waterfalls and never leak data between users.

    Installed when the project uses: sveltekit7 rules1033 tokens on use

  • Vue components

    fe-vue

    Writes and reviews Vue 3.5 single-file components with script setup and the Composition API - keyed lists, props and emits, refs and reactive, pure computeds, watchers with cleanup, navigation links - so they stay reactive, correct and accessible.

    Installed when the project uses: vue, nuxt12 rules1070 tokens on use

  • Web components and Lit

    fe-web-components

    Writes and reviews custom elements, plain or with Lit 3 - names, lifecycle, attributes and properties, shadow DOM styling, events, form-associated controls with ElementInternals, accessibility across the shadow boundary.

    Installed when the project uses: lit, webc9 rules1077 tokens on use

Accessibility

  • Accessible forms

    fe-a11y-forms

    Builds and reviews accessible forms in any stack (HTML, React, Vue, Svelte, Angular, Astro) to WCAG 2.2 AA as a target - labels, autocomplete, required fields, grouping, error messages, focus after submit, sign-in without memory tests.

    Installed when the project uses: every web project4 rules875 tokens on use

Performance

  • Web fonts

    fe-fonts

    Loads web fonts fast and without layout shift - self-hosted WOFF2, font-display, a correct preload with crossorigin, subsetting and unicode-range, variable fonts, metric-matched fallbacks, system font stacks, and next/font or @nuxt/fonts.

    Installed when the project uses: every web project6 rules875 tokens on use

  • Images and media delivery

    fe-images

    Delivers images that are light, sharp and stable - AVIF or WebP, srcset and sizes, picture for formats and art direction, width and height against layout shift, an eager high-priority LCP image, lazy loading below the fold, video instead of GIF, SVG for icons and logos, and the framework image components.

    Installed when the project uses: every web project9 rules1008 tokens on use
