# Internationalisation reference

Depth for the `fe-i18n` skill. Rule ids in brackets: `frontend-skills explain <id>`. Baseline from web-features 3.45.0 and versions from the npm registry, read on 2026-11-11; plural categories from `Intl.PluralRules` in Node.js 26.13.0.

## Intl recipes [i18n/intl-format, i18n/explicit-locale]

| Need | Code | Baseline |
| --- | --- | --- |
| Date | `new Intl.DateTimeFormat(locale, { dateStyle: 'medium', timeZone })` | widely |
| Number | `new Intl.NumberFormat(locale).format(1234.5)` | widely |
| Price | `new Intl.NumberFormat(locale, { style: 'currency', currency: 'PLN' })` | widely |
| Percent, units | `{ style: 'percent' }`, `{ style: 'unit', unit: 'kilometer' }` | widely |
| "3 days ago" | `new Intl.RelativeTimeFormat(locale, { numeric: 'auto' }).format(-3, 'day')` | widely |
| "A, B and C" | `new Intl.ListFormat(locale, { type: 'conjunction' }).format(list)` | widely |
| Sorting | `list.sort(new Intl.Collator(locale, { numeric: true }).compare)` | widely |
| Plural category | `new Intl.PluralRules(locale).select(n)` | widely |
| Language names | `new Intl.DisplayNames([locale], { type: 'language' }).of('pl')` | widely |
| Characters, words | `new Intl.Segmenter(locale, { granularity: 'grapheme' })` | widely (2026-10) |
| Durations | `Intl.DurationFormat` | newly; feature-detect |

Create formatters once and reuse them; they are relatively expensive to construct. Output depends on the CLDR data of each browser and Node build, so do not snapshot formatted strings across environments.

## Plurals [i18n/plural-rules, i18n/same-keys]

| Language | Categories (cardinal) |
| --- | --- |
| English, German, Spanish | one, other |
| French | one, many, other |
| Polish | one, few, many, other |
| Czech, Slovak | one, few, many, other |
| Russian, Ukrainian | one, few, many, other |
| Arabic | zero, one, two, few, many, other |
| Japanese, Chinese, Korean | other |

Check any language with `new Intl.PluralRules('pl').resolvedOptions().pluralCategories`.

```text
en: "{count, plural, one {# file} other {# files}}"
pl: "{count, plural, one {# plik} few {# pliki} many {# plików} other {# pliku}}"
select inside plural: "{gender, select, female {She has} male {He has} other {They have}} {count, plural, one {# file} other {# files}}"
```

Put `select` outside and `plural` inside, and keep each branch a whole sentence.

## Composite messages [i18n/no-string-concat]

```js
// placeholders and rich text instead of fragments
t('terms', { link: (chunks) => <a href="/terms">{chunks}</a> }) // "I accept the <link>terms</link>"
```

## Direction [i18n/dir-rtl, i18n/logical-properties]

Right-to-left languages include Arabic (`ar`), Hebrew (`he`), Persian (`fa`), Urdu (`ur`), Pashto (`ps`), Sindhi (`sd`), Uyghur (`ug`), Yiddish (`yi`), Dhivehi (`dv`) and Kurdish Sorani (`ckb`).

| Physical | Logical |
| --- | --- |
| `margin-left`, `padding-right` | `margin-inline-start`, `padding-inline-end` |
| `left: 0`, `right: 0` | `inset-inline-start: 0`, `inset-inline-end: 0` |
| `text-align: left` | `text-align: start` |
| `border-top-left-radius` | `border-start-start-radius` |
| `width` / `height` (in vertical text) | `inline-size` / `block-size` |

- `dir="auto"` on inputs, textareas and elements that show user names or comments; `<bdi>` around inserted values of unknown direction.
- Mirror direction icons with `:dir(rtl)`; never mirror logos, media controls, clocks or check marks.

## Text length

Translations are often longer than English (German and Finnish labels can be much longer, short UI strings grow the most). Avoid fixed widths on buttons and tabs, allow wrapping, test with a pseudo-locale, and never put UI text in images.

## Language switcher

```html
<nav aria-label="Language">
  <a href="/pl/cennik" hreflang="pl" lang="pl">Polski</a>
  <a href="/pricing" hreflang="en" lang="en" aria-current="true">English</a>
</nav>
```

Name each language in itself, do not use flags for languages, keep the switcher in the same place on every page, and keep the user on the same page in the new language.
