The rule dictionary

Every rule has a stable id such as a11y/img-alt, one sentence, a severity and at least one source in a public standard or the vendor's documentation. People, agents, the report and explain all use the same id.

HTML 11 rules

  • html/button-type

    Every button states its type (button, submit or reset); the default is submit.

    minor static

  • html/constraint-attr-type

    Validation attributes match the input type (pattern and maxlength on text-like types, min, max and step on number and date types).

    moderate static

  • html/doctype

    Every HTML document starts with <!doctype html> so the browser renders it in standards mode.

    moderate static

  • html/form-submit

    Fields sit in a form that is handled on its submit event with a submit button, so Enter, autofill and native validation work.

    moderate manual

  • html/icon-from-set

    When the project has an icon set (sprite, icon classes or an Icon component), markup uses it, never a hard-coded path to an icon file.

    minor static

  • html/input-type

    An input for an email address, phone number or URL uses type email, tel or url, not text.

    minor static

  • html/no-number-for-codes

    Codes made of digits (postal codes, card numbers, one-time codes, PINs) use type text with inputmode numeric, not type number.

    moderate static

  • html/password-autocomplete

    Password fields say current-password (sign-in) or new-password (sign-up, change) in autocomplete, and never use autocomplete off.

    moderate static

  • html/picture-img

    Every picture element ends with an img that has src, alt, width and height; source elements alone render nothing.

    serious static

  • html/project-icons

    Icons use the project's generated icon classes (its icon classes), not separate SVG image files.

    minor static

  • html/required-select-placeholder

    A required single-choice select starts with an empty placeholder option (value=""), so the required check can fail.

    moderate static

CSS 23 rules

  • css/animate-composited

    Animations and transitions change transform and opacity, not layout properties such as width, height, top, left or margin.

    moderate static

  • css/asset-url

    In a bundled project, url() to images and fonts is a relative path or alias the bundler resolves, not a hard-coded root or public/ path.

    minor static

  • css/baseline-check

    Before using a newer CSS feature, check its Baseline status against the project's browser targets and plan the fallback.

    minor manual

  • css/container-type-size

    Query containers use container-type inline-size; size is only for elements that get their height from elsewhere.

    moderate static

  • css/design-tokens

    Colours and spacing come from the project's tokens (custom properties or variables); a literal that has a token, or repeats, is a finding.

    minor static

  • css/gap-over-margins

    Space the children of a flex or grid container with gap, not with margins on the children and last-child exceptions.

    minor manual

  • css/icon-from-set

    With a generated icon set, CSS uses its icon classes or mixin, never a url() hard-coded to an icon file.

    minor static

  • css/light-dark-color-scheme

    A project that uses light-dark() declares color-scheme (light dark) on :root or in a meta tag, or the dark values never apply.

    moderate static

  • css/limited-needs-supports

    CSS that is not Baseline yet (anchor positioning) or only just became Baseline (scroll-driven animations) sits in @supports with a fallback.

    moderate static

  • css/logical-properties

    Sites that run or may run right to left use logical properties (margin-inline-start, inset-inline-end), not left and right.

    minor manual

  • css/nesting-no-concat

    In native CSS nesting, never build class names from "&" plus a suffix (&__title); write the full selector.

    serious static

  • css/no-fixed-height-text

    Boxes that hold text do not combine a fixed height with hidden overflow; use min-height so enlarged or spaced text is not clipped.

    serious static WCAG 1.4.4, 1.4.12 AA

  • css/no-float-layout

    Page and component layout uses grid or flexbox; float is only for wrapping text around media, and clearfix hacks are gone.

    minor static

  • css/no-id-selectors

    Style elements by class, not by id; an id selector outweighs any number of classes and makes the rule hard to override.

    minor static

  • css/no-important

    !important appears only in utility classes, user-preference overrides and third-party overrides, never to win a specificity fight.

    minor static

  • css/no-magic-numbers

    Offsets and spacing use the project's spacing scale or come from layout; hand-tuned one-off values such as top -7px are a finding.

    minor static

  • css/no-stale-prefixes

    No hand-written vendor prefixes for features browsers support unprefixed (border-radius, transitions, transforms, flexbox, gradients).

    minor static

  • css/pause-auto-motion

    Anything that moves, blinks or scrolls on its own for more than five seconds (carousels, marquees, background video) can be paused.

    serious manual WCAG 2.2.2 A

  • css/reduced-motion

    Non-essential motion (entrance animations, parallax, smooth scrolling) respects prefers-reduced-motion.

    moderate static

  • css/rem-helper

    Font sizes and spacing use the project's px-to-rem helper (its rem function), not raw px.

    minor static

  • css/rem-units

    Font sizes are written in rem (or em), never px, in projects without a rem helper; with one, css/rem-helper applies.

    minor static

  • css/unitless-line-height

    line-height is a unitless number (for example 1.5), never px, em or a percentage, so it scales with each element's font size.

    minor static

  • css/z-index-scale

    z-index values come from a named scale (custom properties or Sass variables), not ad hoc numbers such as 999 or 9999.

    minor static

Responsive layout 7 rules

  • responsive/dynamic-viewport-units

    A full-height layout uses 100dvh (or svh) instead of 100vh, which is taller than the visible area on mobile.

    minor static

  • responsive/no-fixed-wide-width

    No layout box gets a fixed width wider than 320 CSS px; cap it with max-width or min(100%, …) so the page reflows on narrow screens.

    serious static WCAG 1.4.10 AA

  • responsive/no-hover-only

    Nothing is revealed on hover alone; content and controls shown on hover also show on keyboard focus and are reachable on touch.

    serious static WCAG 2.1.1 A

  • responsive/no-viewport-font-size

    Text is never sized with viewport units alone (font-size 5vw); fluid type mixes in rem, as in clamp(1rem, 0.9rem + 1vw, 1.5rem).

    serious static WCAG 1.4.4 AA

  • responsive/orientation

    The page works in portrait and landscape; it never locks the orientation or asks people to rotate unless one orientation is essential.

    serious manual WCAG 1.3.4 AA

  • responsive/reflow

    The page reads without sideways scrolling at 320 CSS px and 400% zoom; only tables, maps and similar may scroll both ways.

    serious manual WCAG 1.4.10 AA

  • responsive/viewport-meta

    Every HTML document has <meta name="viewport" content="width=device-width, initial-scale=1">.

    serious static

Accessibility 58 rules

  • a11y/accordion-header

    Each accordion header is a button with aria-expanded inside a heading of the right level; or use details and summary.

    moderate manual WCAG 1.3.1, 4.1.2 A

  • a11y/aria-hidden-focusable

    aria-hidden="true" is never on a focusable element or on an element that contains one.

    serious static WCAG 4.1.2 A

  • a11y/aria-label-generic

    aria-label and aria-labelledby go on controls, landmarks and named roles, never on a plain div, span or p.

    serious static WCAG 4.1.2 A

  • a11y/aria-ref-exists

    Ids named in aria-labelledby, aria-describedby and aria-errormessage exist in the page and are unique.

    serious static WCAG 1.3.1, 4.1.2 A

  • a11y/aria-valid

    Every role value is a real WAI-ARIA role and every aria-* attribute name exists (aria-labelledby, not aria-labeledby).

    serious static WCAG 4.1.2 A

  • a11y/autocomplete-valid

    An autocomplete attribute holds only tokens the HTML standard defines (email, given-name, new-password…).

    serious static WCAG 1.3.5 AA

  • a11y/carousel-controls

    A carousel has named previous and next buttons, a pause button first in its Tab order when it rotates, and stops on hover and focus.

    serious manual WCAG 2.2.2, 4.1.2 A

  • a11y/color-contrast

    Text has a contrast ratio of at least 4.5:1 with its background; large text (24px, or 18.5px bold) at least 3:1.

    serious browser WCAG 1.4.3 AA

  • a11y/combobox-keyboard

    A combobox keeps focus in the input, marks the highlighted option with aria-activedescendant and supports Down, Up, Enter and Escape.

    serious manual WCAG 2.1.1, 4.1.2 A

  • a11y/combobox-on-input

    role="combobox" sits on the input itself (ARIA 1.2), not on a wrapper element that contains the input.

    serious static WCAG 4.1.2 A

  • a11y/control-name

    Every button and link has an accessible name; icon-only controls get visually hidden text or aria-label.

    critical static WCAG 4.1.2, 2.4.4 A

  • a11y/dialog-focus

    A modal moves focus inside on open, keeps Tab inside, closes on Escape, and returns focus to the control that opened it.

    serious manual WCAG 2.4.3, 2.1.2 A

  • a11y/dialog-name

    Every dialog has an accessible name, usually aria-labelledby pointing at its visible heading.

    serious static WCAG 4.1.2 A

  • a11y/dialog-native

    Build dialogs on the native <dialog> element opened with showModal() rather than a div with role="dialog".

    minor static WCAG 2.4.3, 4.1.2 A

  • a11y/focus-not-obscured

    Sticky headers, footers, cookie banners and chat widgets never fully cover the element that has keyboard focus.

    serious manual WCAG 2.4.11 AA

  • a11y/focus-route-change

    After a client-side route change, focus moves to the new page's heading or main region and the new title is announced.

    moderate manual WCAG 2.4.3, 4.1.3 A

  • a11y/focus-visible

    Never remove the focus outline without drawing a visible replacement for keyboard focus.

    serious static WCAG 2.4.7 AA

  • a11y/font-size-relative

    The root font size is not set in pixels, so text follows the reader's default size; use rem for type.

    minor static WCAG 1.4.4 AA

  • a11y/form-errors

    An input error is shown in text next to the field, tied to it with aria-describedby, and says how to fix it.

    serious manual WCAG 3.3.1, 3.3.3, 4.1.3 AA

  • a11y/hover-content-dismissible

    Tooltips and popups shown on hover or focus close with Escape, stay while the pointer moves onto them, and do not vanish on a timer.

    moderate manual WCAG 1.4.13 AA

  • a11y/html-lang

    The html element names the language of the page in a non-empty lang attribute.

    serious static WCAG 3.1.1 A

  • a11y/iframe-title

    Every visible iframe has a title that says what it contains (map, video, payment form).

    serious static WCAG 4.1.2 A

  • a11y/img-alt

    Every img and area element has an alt attribute; a decorative image has alt="".

    critical static WCAG 1.1.1 A

  • a11y/input-label

    Every form field has a programmatic label (label element, aria-label or aria-labelledby); a placeholder is not a label.

    critical static WCAG 1.3.1, 3.3.2, 4.1.2 A

  • a11y/landmarks

    Each page has one main landmark, all content sits inside landmarks, and repeated landmarks of a kind have distinct labels.

    moderate browser WCAG 1.3.1, 2.4.1 A

  • a11y/lang-valid

    Every lang value is a valid BCP 47 language tag ("en", "en-GB", "pl"), never "en_US" or a language name.

    serious static WCAG 3.1.1, 3.1.2 AA

  • a11y/link-is-link

    An <a> is a real link with an href; an action is a <button>, never <a> without href, href="#" or javascript:.

    serious static WCAG 2.1.1, 4.1.2 A

  • a11y/media-alternative

    Recorded audio has a transcript; recorded video has audio description of what is only shown, or a full text alternative.

    serious manual WCAG 1.2.1, 1.2.3, 1.2.5 AA

  • a11y/menu-keyboard

    Menus implement their keys - arrows move between items, Enter activates, Escape closes and returns focus to the button.

    serious manual WCAG 2.1.1 A

  • a11y/menu-not-for-site-nav

    Site navigation is a nav with a list of links and disclosure buttons, not role="menu" or role="menubar".

    moderate static WCAG 4.1.2 A

  • a11y/no-autoplay-audio

    No audio plays automatically; autoplaying video is muted, and any sound longer than 3 seconds can be paused or stopped.

    moderate static WCAG 1.4.2 A

  • a11y/no-click-on-static

    A click handler belongs on a button or link; a static element with one also needs a role, tabindex and a key handler.

    serious static WCAG 2.1.1, 4.1.2 A

  • a11y/no-color-only

    Colour is never the only cue; errors, states, links in text and chart series also differ by text, icon, shape or underline.

    serious browser WCAG 1.4.1 A

  • a11y/no-flash

    Nothing flashes more than three times in any one second, unless the flash is small and below the general and red thresholds.

    critical manual WCAG 2.3.1 A

  • a11y/no-keyboard-trap

    Keyboard focus can always leave a component with Tab, Shift+Tab or Escape; only an open modal keeps focus inside.

    critical manual WCAG 2.1.2 A

  • a11y/no-meta-refresh

    No meta refresh reloads or redirects the page after a delay; redirect on the server or let people choose.

    serious static WCAG 2.2.1 A

  • a11y/non-text-contrast

    Borders of fields, checkboxes, toggles, focus rings and meaningful icons have at least 3:1 contrast with their neighbours.

    serious manual WCAG 1.4.11 AA

  • a11y/option-no-interactive

    Options in a listbox or combobox popup hold only text and images, never links, buttons or fields.

    serious static WCAG 4.1.2 A

  • a11y/page-title

    Every HTML document has a title element that says what the page is about.

    serious static WCAG 2.4.2 A

  • a11y/pause-auto-motion

    Anything that moves, blinks, scrolls or updates by itself for more than 5 seconds has a visible pause or stop control.

    serious manual WCAG 2.2.2 A

  • a11y/popup-button-expanded

    A control that opens a popup (aria-haspopup or role="combobox") has aria-expanded that follows the open state.

    serious static WCAG 4.1.2 A

  • a11y/positive-tabindex

    No element has a tabindex greater than 0; focus order follows the source order.

    serious static WCAG 2.4.3 A

  • a11y/prefer-native-element

    Use the native element instead of a role it already provides (button, a href, input, h1–h6, nav, main, ul, li).

    minor static WCAG 4.1.2 A

  • a11y/reflow

    At 320 CSS pixels wide (400% zoom) content reflows into one column with no horizontal scrolling, except tables, maps and similar.

    serious manual WCAG 1.4.10 AA

  • a11y/scrollable-region-focusable

    A scrolling region with no focusable content inside can itself take focus (tabindex="0") and has a name.

    serious browser WCAG 2.1.1 A

  • a11y/skip-link

    Pages with repeated header or navigation start with a "Skip to main content" link whose target exists and takes focus.

    moderate browser WCAG 2.4.1 A

  • a11y/state-exposed

    Custom toggles, disclosures and selections expose their state (aria-expanded, aria-pressed, aria-checked, aria-selected).

    serious manual WCAG 4.1.2 A

  • a11y/status-message-live

    Messages that appear without moving focus (saved, results, errors, progress) are announced through a live region.

    serious manual WCAG 4.1.3 AA

  • a11y/table-caption

    A data table has a name, from a caption element or aria-labelledby pointing at the heading above it.

    minor manual WCAG 1.3.1 A

  • a11y/table-headers

    Data tables mark their header cells with th (with scope when needed); layout tables carry role="presentation".

    serious static WCAG 1.3.1 A

  • a11y/table-sort

    Sortable columns use a button inside the th, and aria-sort only on the header of the column that is sorted.

    moderate manual WCAG 2.1.1, 4.1.2 A

  • a11y/tabs-keyboard

    A tab list is one Tab stop; Left and Right Arrow (Up and Down when vertical), Home and End move between tabs.

    serious manual WCAG 2.1.1 A

  • a11y/tabs-selected

    Every role="tab" carries aria-selected, true on the active tab and false on the others.

    serious static WCAG 4.1.2 A

  • a11y/target-size

    Pointer targets are at least 24 by 24 CSS pixels, or spaced so a 24px circle on each does not touch another target.

    serious browser WCAG 2.5.8 AA

  • a11y/text-spacing

    Text survives line height 1.5, paragraph spacing 2em, letter spacing 0.12em and word spacing 0.16em without being cut off.

    serious browser WCAG 1.4.12 AA

  • a11y/toast-timing

    Toasts with actions or information the user needs do not disappear on a timer; others stay long enough and pause on hover and focus.

    moderate manual WCAG 2.2.1, 4.1.3 A

  • a11y/video-captions

    Recorded video with speech or meaningful sound has synchronised captions, for example a <track kind="captions">.

    critical static WCAG 1.2.2 A

  • a11y/zoom-not-blocked

    The viewport never disables zoom (no user-scalable=no, no maximum-scale below 2).

    critical static WCAG 1.4.4 AA

Performance 26 rules

  • perf/bfcache-no-unload

    No code listens to the unload event; use pagehide or visibilitychange so the page can use the back/forward cache.

    moderate static

  • perf/cache-static-assets

    Content-hashed assets are cached for a year as immutable; HTML is revalidated (no-cache), never cached long.

    moderate browser

  • perf/code-split

    JavaScript is split by route, and features that most visits do not use load on demand with dynamic import().

    moderate browser

  • perf/css-no-import

    Shipped CSS does not chain stylesheets with @import; link them in the HTML or combine them in a build.

    moderate static

  • perf/field-data-p75

    Claims about Core Web Vitals come from field data at the 75th percentile, not from a Lighthouse score.

    minor manual

  • perf/font-display

    Every @font-face and Google Fonts URL sets font-display (swap or optional) so text is visible while the font loads.

    minor static

  • perf/font-fallback-metrics

    The fallback font is adjusted to the web font's metrics (size-adjust and overrides) so the swap does not shift the layout.

    minor manual

  • perf/font-preconnect

    Fonts are self-hosted, or the font CDN's file origin (fonts.gstatic.com) is preconnected with crossorigin.

    minor static

  • perf/font-preload-crossorigin

    A font preload has crossorigin (and type font/woff2); without it the preload is wasted and the font is fetched twice.

    moderate static

  • perf/font-woff2

    Web fonts are served as WOFF2; TTF, OTF, EOT and plain WOFF files are dead weight for current browsers.

    moderate static

  • perf/gif-to-video

    Animations longer than a small icon are shipped as a muted, looping MP4 or WebM video, not as a GIF over 100 KiB.

    moderate static

  • perf/img-dimensions

    Every img has width and height attributes (or a CSS aspect ratio) so the browser reserves its space.

    moderate static

  • perf/img-modern-format

    Photos and large raster images are served as AVIF or WebP at the size they are shown, not as large JPEG or PNG files.

    moderate browser

  • perf/large-image

    An image file in the source stays under the image budget (250 KB by default); larger ones are resized or re-encoded.

    moderate static

  • perf/layout-shift

    Nothing moves after it appears - space is reserved for images, embeds, ads and late content (CLS 0.1 or less).

    moderate browser

  • perf/lcp-image

    The LCP image is in the initial HTML, not lazy, and has fetchpriority="high"; a CSS background LCP image is preloaded.

    moderate browser

  • perf/lcp-image-not-lazy

    The image most likely to be the Largest Contentful Paint (hero, high priority) is never loading="lazy".

    moderate static

  • perf/lcp-image-priority

    The image that is likely the LCP element loads eagerly with fetchpriority high; it is never lazy-loaded.

    serious static

  • perf/lighthouse-ci

    Lighthouse in CI runs each URL several times, asserts on metrics and categories with realistic thresholds, and never demands a perfect 100.

    minor manual

  • perf/no-legacy-javascript

    Do not ship polyfills and down-level transforms for features your target browsers already support; declare targets once.

    minor browser

  • perf/no-whole-library-import

    Client code does not import all of lodash or moment; use lodash-es, per-method imports, Intl or the platform.

    moderate static

  • perf/render-blocking-script

    A script in the head loads with defer, async or type="module", never as a plain blocking script.

    moderate static

  • perf/srcset-sizes

    A srcset with width descriptors (400w, 800w) comes with a sizes attribute that matches the image's displayed width.

    moderate static

  • perf/third-party-async

    Third-party scripts load with async or defer (or a framework strategy such as lazyOnload), never as parser-blocking tags.

    moderate static

  • perf/third-party-cost

    Each third-party script earns its place, loads late, and heavy embeds (video, maps, chat) start as a lightweight facade.

    moderate browser

  • perf/yield-long-tasks

    Main-thread work over 50 ms is split and yields, and event handlers do the visible update first (INP 200 ms or less).

    moderate manual

SEO 9 rules

  • seo/canonical-valid

    A page has at most one rel="canonical", in the head, with an absolute URL of an indexable page and no fragment.

    moderate static

  • seo/hreflang-valid

    hreflang values are ISO 639-1 language codes with an optional script and ISO 3166-1 region (or x-default), linking absolute URLs.

    moderate static

  • seo/http-status

    Missing pages return 404 or 410, moved pages 301 or 308, and a client-rendered error view is not served with 200.

    moderate browser

  • seo/indexable

    Pages meant to rank are crawlable and carry no noindex (meta robots or X-Robots-Tag) in production.

    serious browser

  • seo/jsonld-type-supported

    Structured data for rich results uses types in Google's current search gallery, not retired ones such as FAQPage or HowTo.

    minor static

  • seo/jsonld-valid

    Every JSON-LD block is valid JSON with "@context" "https://schema.org" and a schema.org @type.

    moderate static

  • seo/meta-description

    Each indexable page has its own meta description that summarises that page.

    moderate static

  • seo/og-absolute-url

    Open Graph and social image and URL tags (og:image, og:url, twitter:image) use absolute https URLs.

    minor static

  • seo/title-unique

    Each page has its own descriptive title, page topic first and site name last, in the page's language.

    minor manual

Internationalisation 7 rules

  • i18n/dir-rtl

    Pages in right-to-left languages (Arabic, Hebrew, Persian, Urdu) set dir="rtl" on html together with lang.

    serious static

  • i18n/explicit-locale

    Intl formatters and toLocale*String() receive the app's active locale instead of relying on the runtime default.

    minor static

  • i18n/intl-format

    Dates, times, numbers and prices are formatted with Intl for the user's locale, never assembled from parts.

    moderate static

  • i18n/logical-properties

    In projects with a right-to-left locale, layout uses logical properties (margin-inline-start, inset-inline-end, text-align start).

    moderate manual

  • i18n/no-string-concat

    User-facing sentences are one message with placeholders, never joined from translated fragments and values.

    moderate static

  • i18n/plural-rules

    Plurals use the locale's plural rules (ICU plural or Intl.PluralRules), never count === 1 ? singular : plural.

    moderate static

  • i18n/same-keys

    Every locale file has the same keys and placeholders as the source locale, and the plural forms its language needs.

    serious manual

Security 9 rules

  • security/csp-meta-ignored

    frame-ancestors, report-uri, sandbox and X-Frame-Options are sent as HTTP headers; in a meta tag they do nothing.

    moderate static

  • security/csp-strict

    Production pages send a strict Content Security Policy (nonces or hashes with strict-dynamic, object-src none, base-uri none).

    moderate browser

  • security/https-only

    Every page and every resource it loads use HTTPS; no mixed content and no http:// links to your own site.

    serious browser

  • security/no-eval

    Front-end code never runs strings as code - no eval, new Function or string arguments to setTimeout and setInterval.

    serious static

  • security/no-secrets-in-client-env

    Secrets never use a client-exposed environment prefix (NEXT_PUBLIC_, VITE_, PUBLIC_, NUXT_PUBLIC_); they stay on the server.

    critical static

  • security/postmessage-origin

    postMessage names an exact target origin, and every window message listener checks event.origin against an allowlist.

    serious static

  • security/raw-html-sink

    Never pass user or remote data to a raw HTML sink (innerHTML, dangerouslySetInnerHTML, v-html, {@html}) without sanitizing it.

    serious static

  • security/sri-cdn

    Versioned files from a public CDN carry Subresource Integrity (integrity plus crossorigin), or are self-hosted.

    moderate static

  • security/window-open-noopener

    window.open for another site passes "noopener" (and "noreferrer" when needed) so the new page cannot control yours.

    minor static

JavaScript 13 rules

  • js/asset-import

    In a bundled project, images, fonts and media in component markup are imported or use the base-path helper, not hard-coded root paths.

    moderate static

  • js/document-write

    Never insert content with document.write; create elements or load scripts with the DOM.

    moderate static

  • js/feature-detect

    Test for the feature you need (in, CSS.supports, matchMedia), not the browser name in navigator.userAgent.

    minor static

  • js/fetch-check-ok

    After fetch, check response.ok (or the status) before reading the body; fetch does not reject on 404 or 500.

    moderate static

  • js/listener-cleanup

    Listeners, timers and observers a view starts are removed when it goes away; one AbortController signal can end them all.

    moderate manual

  • js/no-empty-catch

    A catch block never swallows an error silently; handle it, report it, or say in a comment why it is safe to ignore.

    moderate static

  • js/no-eval

    Never run strings as code - no eval, new Function, or a string as the first argument of setTimeout or setInterval.

    serious static

  • js/no-floating-promises

    Every promise is awaited, returned or given a .catch(); an async call is never left floating.

    moderate manual

  • js/no-inline-handlers

    Attach event handlers from script with addEventListener, not with onclick="..." attributes in HTML.

    moderate static

  • js/no-var

    Declare variables with const, or let when they are reassigned; never with var.

    minor static

  • js/passive-listeners

    Mark touchstart, touchmove and wheel listeners { passive true } unless the handler really calls preventDefault().

    moderate static

  • js/strict-equality
