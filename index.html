Front-end skills for every AI coding agent

One command learns your project's stack, installs only the skills that fit it for each coding agent you use, and reports what to fix in your HTML, CSS, JavaScript and framework code: the rule, the line, why it matters and the source.

Run it in your project's folder (Node.js 20 or newer):

npx github:dawidolko/frontend-skills init

Three steps, one command

init runs all three. Each step is also a command of its own.

your project

  1. 1. Learn your stack

    Reads package.json, lockfiles and config files, with no network. Writes .frontend-skills/profile.json: frameworks and versions, styling, tests, and your own helpers, such as a rem function or generated icon classes.

    profile.json

  2. 2. Install for your agents

    Finds the agents the project uses and writes only the skills that match the stack, in each agent's own format: skills folders, rule files scoped to file types, one short block in AGENTS.md or CLAUDE.md. Every file is recorded.

    skills + rule files

  3. 3. Audit and fix

    Checks the source against the dictionary and writes a report a person can act on. Your agent reads the condensed JSON and fixes the code; you read the Markdown report.

    frontend-report.md

code your agent writes to the rules

Free, open source, yours to read

MIT licence. No account, no payment, no telemetry. The tool makes no network call unless you start one: audit --url asks before it fetches Lighthouse and axe-core. It runs straight from GitHub with npx; nothing is installed globally.

Cheap to keep loaded

An agent always loads only the name and description of each installed skill. For all 50 skills that is about 4219 tokens; a skill's body (about 937 tokens on average) loads only when a task needs it.

Tokens are estimates by frontend-skills estimate v1 (calibrated on o200k), measured with frontend-skills tokens --all when this site was built.

What automated checks cannot do

Static checks and browser audits find only part of the accessibility problems. Whether an alt text says the right thing, whether the reading order makes sense, whether a custom widget traps the keyboard: a person has to look. The report lists those as a checklist next to the findings. The tool helps you work to WCAG 2.2 AA; it certifies nothing.
