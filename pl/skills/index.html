Skille według technologii

Skill to krótka instrukcja dla agenta AI w otwartym formacie Agent Skills. Instalowane są tylko skille pasujące do stacku projektu; każdy wymienia reguły, których uczy. Treść skilli jest po angielsku, bo czytają ją agenci.

Podstawy

  • Native forms and validation

    fe-forms

    Builds and reviews HTML forms that work natively - the right input types and inputmode, autocomplete tokens, constraint validation and custom messages, select placeholders, file inputs, and submission through the form's submit event. Accessibility of forms is in fe-a11y-forms.

    Instalowany, gdy projekt używa: każdego projektu webowego9 regułprzy użyciu: 954 tokeny

  • HTML documents and semantics

    fe-html

    Writes and reviews HTML documents and templates (plain HTML, JSX, Vue, Svelte, Astro, Angular) with valid structure, semantic elements, landmarks, headings, images and buttons that work for everyone.

    Instalowany, gdy projekt używa: każdego projektu webowego6 regułprzy użyciu: 869 tokenów

  • JavaScript in the browser

    fe-javascript

    Writes and reviews browser JavaScript (plain scripts, modules, framework script blocks) - equality, declarations, async and fetch errors, DOM events, assets through the bundler - so it fails loudly, stays fast and keeps working when moved.

    Instalowany, gdy projekt używa: każdego projektu webowego13 regułprzy użyciu: 1070 tokenów

  • Responsive design

    fe-responsive

    Makes pages and components work from 320 CSS px phones to wide screens and at 400% zoom - viewport meta, fluid type and space, content breakpoints and container queries, no fixed wide boxes, dvh units, touch targets, no hover-only content, orientation and print.

    Instalowany, gdy projekt używa: każdego projektu webowego9 regułprzy użyciu: 1080 tokenów

  • TypeScript

    fe-typescript

    Writes and reviews TypeScript for front-end apps (TypeScript 7, React, Vue, Svelte, Angular, Astro) - strict config, no any, types checked at the boundaries (API, storage, forms), narrowing instead of casts, a tsconfig that builds on 6 and 7.

    Instalowany, gdy projekt używa: typescript6 regułprzy użyciu: 1016 tokenów

    fe-css-layout

    fe-motion

    Instalowany, gdy projekt używa: każdego projektu webowego4 regułyprzy użyciu: 838 tokenów

    fe-sass

    Writes and reviews Sass (SCSS) for Dart Sass - the module system with @use and @forward, sass:math and sass:color, division, placeholders, the project's px-to-rem helper - and says when plain CSS now does the job.

    Instalowany, gdy projekt używa: sass9 regułprzy użyciu: 1016 tokenów

    fe-tailwind

    Writes and reviews Tailwind CSS 4 code - CSS-first setup with @import and @theme, complete class names, tokens instead of arbitrary values, conflict-free class lists, sr-only labels, focus and reduced-motion variants.

    Instalowany, gdy projekt używa: tailwind10 regułprzy użyciu: 1097 tokenów

    Instalowany, gdy projekt używa: każdego projektu webowego8 regułprzy użyciu: 956 tokenów

  • Web fonts

    fe-fonts

    Loads web fonts fast and without layout shift - self-hosted WOFF2, font-display, a correct preload with crossorigin, subsetting and unicode-range, variable fonts, metric-matched fallbacks, system font stacks, and next/font or @nuxt/fonts.

Praca z narzędziem

  • Audit the project

    fe-audit

    Audits a front-end project with frontend-skills - runs the static audit (and the page audit with --url when a page is running), reads the condensed JSON, explains the top findings by rule id with their source, lists what needs a person, and proposes an order of fixes.

    Instalowany, gdy projekt używa: każdego projektu webowego5 regułprzy użyciu: 778 tokenów

  • Build a component

    fe-component

    Builds a new UI component the right way round in any stack - native semantics first, the keyboard model from the WAI-ARIA APG pattern, names and states, every visual state, responsive and reduced motion, the project helpers and tokens, tests by role, then the audit.

    Instalowany, gdy projekt używa: każdego projektu webowego7 regułprzy użyciu: 972 tokeny

  • Fix findings

    fe-fix

    Fixes front-end audit findings by rule id - smallest correct change first, shared components before pages, the rule's own fix and source, re-running audit --changed after each fix, and never suppressing a finding without the rule id and a reason.

    Instalowany, gdy projekt używa: każdego projektu webowego2 regułyprzy użyciu: 670 tokenów

  • Learn the project

    fe-learn

    Teaches the agent this project before front-end work - runs frontend-skills init or learn, reads the profile (stack, versions, helpers), confirms detected conventions such as the rem function, icon build and tokens with the person, and records confirmed lessons.

    Instalowany, gdy projekt używa: każdego projektu webowego1 regułaprzy użyciu: 748 tokenów

  • Review a change

    fe-review

    Reviews a diff or pull request of front-end code - runs audit --changed, maps the touched files to their skills, walks the manual rules of those skills (keyboard, screen reader, motion, content), and reports findings by rule id with file, line and fix.

    Instalowany, gdy projekt używa: każdego projektu webowego5 regułprzy użyciu: 787 tokenów
