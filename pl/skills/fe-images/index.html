Wydajność

Images and media delivery

Delivers images that are light, sharp and stable - AVIF or WebP, srcset and sizes, picture for formats and art direction, width and height against layout shift, an eager high-priority LCP image, lazy loading below the fold, video instead of GIF, SVG for icons and logos, and the framework image components. Use when adding or reviewing images, a hero, a gallery, or when LCP or CLS is poor.

Jak go używać

Po instalacji agent sam ładuje skill, gdy zadanie pasuje do jego opisu. Możesz też poprosić o niego własnymi słowami, na przykład:

A żeby sprawdzić i poprawić pracę:

  • Użyj skilla fe-images na tym pliku.
  • Uruchom audyt front-endu na moich zmianach i popraw wszystko, co poważne.
  • Wyjaśnij perf/img-dimensions i popraw to tutaj.

Reguły, których uczy

  • perf/img-dimensions

    Every img has width and height attributes (or a CSS aspect ratio) so the browser reserves its space.

    umiarkowanastatyczne

  • perf/lcp-image-priority

    The image that is likely the LCP element loads eagerly with fetchpriority high; it is never lazy-loaded.

    poważnastatyczne

  • perf/srcset-sizes

    A srcset with width descriptors (400w, 800w) comes with a sizes attribute that matches the image's displayed width.

    umiarkowanastatyczne

  • html/picture-img

    Every picture element ends with an img that has src, alt, width and height; source elements alone render nothing.

    poważnastatyczne

  • perf/img-modern-format

    Photos and large raster images are served as AVIF or WebP at the size they are shown, not as large JPEG or PNG files.

    umiarkowanaw przeglądarce

  • perf/large-image

    An image file in the source stays under the image budget (250 KB by default); larger ones are resized or re-encoded.

    umiarkowanastatyczne

  • perf/gif-to-video

    Animations longer than a small icon are shipped as a muted, looping MP4 or WebM video, not as a GIF over 100 KiB.

    umiarkowanastatyczne

  • html/project-icons

    Icons use the project's generated icon classes (its icon classes), not separate SVG image files.

    drobnastatyczne

  • a11y/img-alt

    Every img and area element has an alt attribute; a decorative image has alt="".

    krytycznastatyczneWCAG 1.1.1

Skrót reguł

Ta część jest kopiowana do zawężonego pliku reguł każdego agenta, więc musi być zrozumiała sama w sobie:

  • Every <img> has width and height (or a CSS aspect-ratio) so space is reserved (perf/img-dimensions).
  • The likely LCP image is eager with fetchpriority="high"; never loading="lazy" on it (perf/lcp-image-priority).
  • Images below the first screen get loading="lazy"; only one or two images get fetchpriority="high".
  • A srcset with w descriptors always has a matching sizes (perf/srcset-sizes).
  • <picture> ends with an <img> carrying src, alt, width and height (html/picture-img).
  • Photos are AVIF or WebP at the size they are shown, not large JPEG or PNG (perf/img-modern-format).
  • No image file over the budget, 250 KB by default (perf/large-image); no GIF over 100 KiB, use a muted looping video (perf/gif-to-video).
  • Every image has alt: the meaning, or alt="" when decorative (a11y/img-alt).
  • Use the framework's image component when there is one; it writes srcset, sizes and formats for you.
  • Logos are SVG; icons come from the project's generated icon set, never an <img> of an icon file (html/project-icons).
  • The LCP image is in the HTML, not injected by JavaScript or hidden in a CSS background.

Kroki, które wykonuje agent

  1. Find the image pipeline first: next/image, @nuxt/image, Astro <Image> from astro:assets, Angular NgOptimizedImage, SvelteKit enhanced:img, or a build plugin. Use it instead of raw <img>.
  2. For each image decide: LCP candidate (eager, fetchpriority="high"), in first view (eager), or below (lazy).
  3. Write width/height from the file's intrinsic size and let CSS scale it: img { max-width: 100%; height: auto; }.
  4. Generate widths that match the layout (for example 400, 800, 1200, 1600) and describe the rendered width in sizes.
  5. Encode photos as AVIF (WebP or JPEG fallback in <picture> only if the targets need it); keep PNG for sharp screenshots if smaller, SVG for vector art.
  6. For a CSS background that is the LCP element, preload it with <link rel="preload" as="image" fetchpriority="high"> or turn it into an <img>.

Jak agent sprawdza swoją pracę

  • npx github:dawidolko/frontend-skills audit --changed reports images without size, a lazy LCP candidate, srcset without sizes, a picture without img, oversized files and GIFs.
  • audit --url <page> adds Lighthouse's image delivery and LCP discovery insights for the rendered page.
  • By hand: DevTools Network filtered to images on a mobile profile; the Performance panel names the LCP element.
