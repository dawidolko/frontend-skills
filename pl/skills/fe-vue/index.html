Vue components

Writes and reviews Vue 3.5 single-file components with script setup and the Composition API - keyed lists, props and emits, refs and reactive, pure computeds, watchers with cleanup, navigation links - so they stay reactive, correct and accessible. Use when creating or editing a .vue file or a composable, fixing a value that does not update, or when asked to review Vue code.

fe-vuevue, nuxt12 regułładowane zawsze: 81 tokenów; przy użyciu: 1070 tokenów; w referencjach na żądanie: 1926 tokenów.

A żeby sprawdzić i poprawić pracę:

  • Użyj skilla fe-vue na tym pliku.
  • Uruchom audyt front-endu na moich zmianach i popraw wszystko, co poważne.
  • Wyjaśnij vue/require-v-for-key i popraw to tutaj.

Reguły, których uczy

  • vue/require-v-for-key

    Every v-for gives its items a :key from the data; on a template v-for the key goes on the template tag.

    umiarkowanastatyczne

  • vue/no-index-key

    A v-for key comes from the item's data, not from the loop index, when the list can change.

    umiarkowanastatyczne

  • vue/no-v-if-with-v-for

    Never put v-if and v-for on the same element; filter in a computed list or move v-if to a wrapper.

    umiarkowanastatyczne

  • vue/no-mutating-props

    A component never changes its props (or objects and arrays inside them); it emits an event or keeps a local copy.

    umiarkowanastatyczne

  • vue/ref-value-in-script

    In script code, read and compare a ref or computed through .value; the ref object itself is always truthy.

    umiarkowanastatyczne

  • vue/no-reactivity-loss

    Never destructure or reassign a reactive() object; use toRefs, a ref, or change its properties.

    umiarkowanastatyczne

  • vue/computed-pure

    A computed getter only derives a value - no async work, no requests and no changes to other state.

    umiarkowanastatyczne

  • vue/detailed-props

    Declare props with their types (an object with type, or a TypeScript type), not as a bare array of names.

    drobnastatyczne

  • vue/multi-word-names

    Name components with two or more words (TodoItem, not Item); App, pages and layouts are exempt.

    drobnastatyczne

  • vue/link-for-navigation

    Navigate with RouterLink or NuxtLink, not a button whose click handler only calls router.push or navigateTo.

    umiarkowanastatyczneWCAG 4.1.2

  • a11y/no-click-on-static

    A click handler belongs on a button or link; a static element with one also needs a role, tabindex and a key handler.

    poważnastatyczneWCAG 2.1.1, 4.1.2

  • a11y/input-label

    Every form field has a programmatic label (label element, aria-label or aria-labelledby); a placeholder is not a label.

    krytycznastatyczneWCAG 1.3.1, 3.3.2, 4.1.2

Skrót reguł

Ta część jest kopiowana do zawężonego pliku reguł każdego agenta, więc musi być zrozumiała sama w sobie:

  • Key every v-for with an id from the item (vue/require-v-for-key), never the loop index for a list that changes (vue/no-index-key).
  • Never put v-if and v-for on one element; loop over a computed list (vue/no-v-if-with-v-for).
  • Never change a prop; emit, use defineModel(), or copy to local state (vue/no-mutating-props).
  • In script code read refs and computeds through .value (vue/ref-value-in-script).
  • Never destructure or reassign a reactive() object; use ref, toRefs or Object.assign (vue/no-reactivity-loss).
  • Computed getters only derive: no async, requests or writes (vue/computed-pure).
  • Type props (defineProps<{...}>() or objects with type), never a bare name array (vue/detailed-props).
  • Name components with two or more words (vue/multi-word-names).
  • Navigate with RouterLink/NuxtLink, not a button that calls router.push (vue/link-for-navigation).
  • Clicks go on <button> or links (a11y/no-click-on-static); every field has a label (a11y/input-label).
  • Register composables, watch and lifecycle hooks synchronously in setup; clean up what a watcher or onMounted starts.

Kroki, które wykonuje agent

  1. Check the profile: Vue 3.5 (useId, useTemplateRef, onWatcherCleanup, reactive props destructure, lazy hydration); Nuxt adds fe-nuxt; stores follow fe-state.
  2. Write <script setup lang="ts">; declare defineProps, defineEmits (typed) and defineModel for two-way bindings. Options API code stays Options API unless the task is a migration.
  3. Use ref for state, computed for derived values, watch with onWatcherCleanup or an AbortController for side effects; shallowRef for large data you replace.
  4. Extract reusable logic into useX() composables in composables/ that take refs or getters and return plain objects of refs.
  5. Use useId() for id/for/aria-describedby; move focus to the page heading after a route change; bind text with {{ }}; v-html only for sanitized HTML (see fe-security).
  6. Images and media: import them or use @/assets paths (js/asset-import); icons from the project set (html/project-icons, html/icon-from-set).
  7. Split routes and heavy widgets with () => import(...) and defineAsyncComponent.

Jak agent sprawdza swoją pracę

  • npx github:dawidolko/frontend-skills audit --changed reports missing and index keys, v-if with v-for, prop mutation, refs without .value, lost reactivity, impure computeds, untyped props and single-word names.
  • Run ESLint with eslint-plugin-vue flat/recommended and vue-tsc --noEmit; never silence a rule to pass.
  • Vue DevTools: watch the component tree and the timeline for components that re-render on unrelated changes.
