Polecenia

Każde polecenie uruchamiasz przez npx github:dawidolko/frontend-skills <polecenie>; każde przyjmuje --cwd <folder> i --help. Wynik jest domyślnie krótki; --json daje wynik dla maszyn tam, gdzie ma to sens. Komunikaty narzędzia są po angielsku.

init dostępne

Wykrywa stack i agentów, zapisuje profil, planuje pliki dla każdego agenta, pokazuje plan, pyta, zapisuje, rejestruje każdy plik i uruchamia pierwszy audyt. Gdy nie znajdzie żadnego agenta, pyta, których użyć.

npx github:dawidolko/frontend-skills init
Opcje, tak jak wypisuje je --help
Usage: frontend-skills init [options]

  --agents <ids>     comma-separated: claude, codex, cursor, copilot, gemini, antigravity, devin, opencode, cline, zed, junie, kiro, augment, trae, continue, amazonq, aider (windsurf = devin)
  --format <f>       both (default: skills plus glob-scoped rule files), skills, rules
  --dry-run          show the plan and write nothing
  --yes, -y          write without asking (for scripts)
  --no-audit         skip the first audit

audit dostępne

Sprawdza kod źródłowy według reguł i zapisuje frontend-report.md. Z --url sprawdza też działającą stronę w Twoim Chrome; z --changed tylko zmienione pliki; z --json wypisuje skondensowany wynik dla agentów.

npx github:dawidolko/frontend-skills audit
Opcje, tak jak wypisuje je --help
Usage: frontend-skills audit [path] [options]

  --url <address>     also check a running page (Lighthouse and axe-core in your Chrome; asks before fetching them)
  --changed           only files changed against --base (default HEAD), staged, unstaged or new
  --base <ref>        the git ref for --changed
  --fail-on <level>   critical | serious | moderate | minor | none (default: profile audit.failOn or serious)
  --json              print the condensed JSON for agents instead of the summary
  --report <file>     where to write the Markdown report (default frontend-report.md)
  --no-report         do not write the report
  --yes               fetch the browser tools without asking (with --url)

learn dostępne

Ponownie wykrywa stack po zmianach, pokazuje różnice i aktualizuje profil oraz zainstalowane skille. Z --lesson zapisuje potwierdzoną przez Ciebie lekcję.

npx github:dawidolko/frontend-skills learn
Opcje, tak jak wypisuje je --help
Usage: frontend-skills learn [options]

  (no options)          refresh the profile and the installed skills after the stack changed
  --lesson "<text>"     record a confirmed lesson (one line, no secrets)
  --kind <kind>         convention | command | pitfall (with --lesson; default convention)
  --dry-run             show the changes, write nothing
  --yes, -y             apply without asking

list dostępne

Wypisuje skille pasujące do projektu z ich kosztem w tokenach; --all dla wszystkich skilli, --rules dla słownika.

npx github:dawidolko/frontend-skills list
Opcje, tak jak wypisuje je --help
Usage: frontend-skills list [--all] [--rules] [--json]

explain dostępne

Wypisuje jedną regułę: tytuł, wagę, uzasadnienie, poprawkę, przykłady, źródła i skill, który jej uczy. Wycofany identyfikator prowadzi do reguły, która go zastąpiła.

npx github:dawidolko/frontend-skills explain
Opcje, tak jak wypisuje je --help
Usage: frontend-skills explain <rule id> [--json]

doctor dostępne

Sprawdza dla każdego agenta, które pliki istnieją, czy są aktualne i czy jakiś skill nie jest widoczny dwa razy. Kończy się kodem 1, gdy czegoś brakuje lub coś jest nieaktualne.

npx github:dawidolko/frontend-skills doctor
Opcje, tak jak wypisuje je --help
Usage: frontend-skills doctor [--json]

update dostępne

Instaluje zapisany wybór ponownie z bieżącej wersji. Pliki, które zmieniłeś, zostają i są wymienione.

npx github:dawidolko/frontend-skills update
Opcje, tak jak wypisuje je --help
Usage: frontend-skills update [--dry-run]

uninstall dostępne

Usuwa dokładnie to, co wymienia rejestr instalacji; plik, który zmieniłeś, zostaje.

npx github:dawidolko/frontend-skills uninstall
Opcje, tak jak wypisuje je --help
Usage: frontend-skills uninstall [--dry-run] [--yes]

tokens dostępne

Pokazuje szacowany koszt w tokenach tego, co jest zainstalowane: co każdy agent ładuje zawsze, a co przy użyciu.

npx github:dawidolko/frontend-skills tokens
Opcje, tak jak wypisuje je --help
Usage: frontend-skills tokens [--all] [--json]
