Słownik reguł

Każda reguła ma stały identyfikator, np. a11y/img-alt, jedno zdanie, wagę i co najmniej jedno źródło w publicznym standardzie lub dokumentacji producenta. Ludzie, agenci, raport i explain używają tego samego identyfikatora. Treść reguł jest po angielsku, bo czytają ją agenci.

Reguł: 275.

Żadna reguła nie pasuje do tych filtrów.

Dostępność 58 reguł

  • a11y/accordion-headerEach accordion header is a button with aria-expanded inside a heading of the right level; or use details and summary.umiarkowanaręczneWCAG 1.3.1, 4.1.2
  • a11y/aria-hidden-focusablearia-hidden="true" is never on a focusable element or on an element that contains one.poważnastatyczneWCAG 4.1.2
  • a11y/aria-label-genericaria-label and aria-labelledby go on controls, landmarks and named roles, never on a plain div, span or p.poważnastatyczneWCAG 4.1.2
  • a11y/aria-ref-existsIds named in aria-labelledby, aria-describedby and aria-errormessage exist in the page and are unique.poważnastatyczneWCAG 1.3.1, 4.1.2
  • a11y/aria-validEvery role value is a real WAI-ARIA role and every aria-* attribute name exists (aria-labelledby, not aria-labeledby).poważnastatyczneWCAG 4.1.2
  • a11y/autocomplete-validAn autocomplete attribute holds only tokens the HTML standard defines (email, given-name, new-password…).poważnastatyczneWCAG 1.3.5
  • a11y/carousel-controlsA carousel has named previous and next buttons, a pause button first in its Tab order when it rotates, and stops on hover and focus.poważnaręczneWCAG 2.2.2, 4.1.2
  • a11y/color-contrastText has a contrast ratio of at least 4.5:1 with its background; large text (24px, or 18.5px bold) at least 3:1.poważnaw przeglądarceWCAG 1.4.3
  • a11y/combobox-keyboardA combobox keeps focus in the input, marks the highlighted option with aria-activedescendant and supports Down, Up, Enter and Escape.poważnaręczneWCAG 2.1.1, 4.1.2
  • a11y/combobox-on-inputrole="combobox" sits on the input itself (ARIA 1.2), not on a wrapper element that contains the input.poważnastatyczneWCAG 4.1.2

  • a11y/dialog-nameEvery dialog has an accessible name, usually aria-labelledby pointing at its visible heading.poważnastatyczneWCAG 4.1.2

  • a11y/font-size-relativeThe root font size is not set in pixels, so text follows the reader's default size; use rem for type.drobnastatyczneWCAG 1.4.4

  • a11y/hover-content-dismissibleTooltips and popups shown on hover or focus close with Escape, stay while the pointer moves onto them, and do not vanish on a timer.umiarkowanaręczneWCAG 1.4.13
  • a11y/html-langThe html element names the language of the page in a non-empty lang attribute.poważnastatyczneWCAG 3.1.1
  • a11y/iframe-titleEvery visible iframe has a title that says what it contains (map, video, payment form).poważnastatyczneWCAG 4.1.2
  • a11y/img-altEvery img and area element has an alt attribute; a decorative image has alt="".krytycznastatyczneWCAG 1.1.1
  • a11y/input-labelEvery form field has a programmatic label (label element, aria-label or aria-labelledby); a placeholder is not a label.krytycznastatyczneWCAG 1.3.1, 3.3.2, 4.1.2

  • a11y/lang-validEvery lang value is a valid BCP 47 language tag ("en", "en-GB", "pl"), never "en_US" or a language name.poważnastatyczneWCAG 3.1.1, 3.1.2
  • a11y/link-is-linkAn <a> is a real link with an href; an action is a <button>, never <a> without href, href="#" or javascript:.poważnastatyczneWCAG 2.1.1, 4.1.2
  • a11y/media-alternativeRecorded audio has a transcript; recorded video has audio description of what is only shown, or a full text alternative.poważnaręczneWCAG 1.2.1, 1.2.3, 1.2.5

  • a11y/menu-not-for-site-navSite navigation is a nav with a list of links and disclosure buttons, not role="menu" or role="menubar".umiarkowanastatyczneWCAG 4.1.2
  • a11y/no-autoplay-audioNo audio plays automatically; autoplaying video is muted, and any sound longer than 3 seconds can be paused or stopped.umiarkowanastatyczneWCAG 1.4.2
  • a11y/no-click-on-staticA click handler belongs on a button or link; a static element with one also needs a role, tabindex and a key handler.poważnastatyczneWCAG 2.1.1, 4.1.2
  • a11y/no-color-onlyColour is never the only cue; errors, states, links in text and chart series also differ by text, icon, shape or underline.poważnaw przeglądarceWCAG 1.4.1
  • a11y/no-flashNothing flashes more than three times in any one second, unless the flash is small and below the general and red thresholds.krytycznaręczneWCAG 2.3.1
  • a11y/no-keyboard-trapKeyboard focus can always leave a component with Tab, Shift+Tab or Escape; only an open modal keeps focus inside.krytycznaręczneWCAG 2.1.2
  • a11y/no-meta-refreshNo meta refresh reloads or redirects the page after a delay; redirect on the server or let people choose.poważnastatyczneWCAG 2.2.1
  • a11y/non-text-contrastBorders of fields, checkboxes, toggles, focus rings and meaningful icons have at least 3:1 contrast with their neighbours.poważnaręczneWCAG 1.4.11
  • a11y/option-no-interactiveOptions in a listbox or combobox popup hold only text and images, never links, buttons or fields.poważnastatyczneWCAG 4.1.2

  • a11y/pause-auto-motionAnything that moves, blinks, scrolls or updates by itself for more than 5 seconds has a visible pause or stop control.poważnaręczneWCAG 2.2.2
  • a11y/popup-button-expandedA control that opens a popup (aria-haspopup or role="combobox") has aria-expanded that follows the open state.poważnastatyczneWCAG 4.1.2
  • a11y/positive-tabindexNo element has a tabindex greater than 0; focus order follows the source order.poważnastatyczneWCAG 2.4.3
  • a11y/prefer-native-elementUse the native element instead of a role it already provides (button, a href, input, h1–h6, nav, main, ul, li).drobnastatyczneWCAG 4.1.2

  • a11y/table-captionA data table has a name, from a caption element or aria-labelledby pointing at the heading above it.drobnaręczneWCAG 1.3.1

  • a11y/table-sortSortable columns use a button inside the th, and aria-sort only on the header of the column that is sorted.umiarkowanaręczneWCAG 2.1.1, 4.1.2
  • a11y/tabs-keyboardA tab list is one Tab stop; Left and Right Arrow (Up and Down when vertical), Home and End move between tabs.poważnaręczneWCAG 2.1.1

Wydajność 26 reguł

  • perf/bfcache-no-unloadNo code listens to the unload event; use pagehide or visibilitychange so the page can use the back/forward cache.umiarkowanastatyczne
  • perf/cache-static-assetsContent-hashed assets are cached for a year as immutable; HTML is revalidated (no-cache), never cached long.umiarkowanaw przeglądarce
  • perf/code-splitJavaScript is split by route, and features that most visits do not use load on demand with dynamic import().umiarkowanaw przeglądarce
  • perf/css-no-importShipped CSS does not chain stylesheets with @import; link them in the HTML or combine them in a build.umiarkowanastatyczne
  • perf/field-data-p75Claims about Core Web Vitals come from field data at the 75th percentile, not from a Lighthouse score.drobnaręczne
  • perf/font-displayEvery @font-face and Google Fonts URL sets font-display (swap or optional) so text is visible while the font loads.drobnastatyczne
  • perf/font-fallback-metricsThe fallback font is adjusted to the web font's metrics (size-adjust and overrides) so the swap does not shift the layout.drobnaręczne
  • perf/font-preconnectFonts are self-hosted, or the font CDN's file origin (fonts.gstatic.com) is preconnected with crossorigin.drobnastatyczne
  • perf/font-preload-crossoriginA font preload has crossorigin (and type font/woff2); without it the preload is wasted and the font is fetched twice.umiarkowanastatyczne
  • perf/font-woff2Web fonts are served as WOFF2; TTF, OTF, EOT and plain WOFF files are dead weight for current browsers.umiarkowanastatyczne
  • perf/gif-to-videoAnimations longer than a small icon are shipped as a muted, looping MP4 or WebM video, not as a GIF over 100 KiB.umiarkowanastatyczne
  • perf/img-dimensionsEvery img has width and height attributes (or a CSS aspect ratio) so the browser reserves its space.umiarkowanastatyczne
  • perf/img-modern-formatPhotos and large raster images are served as AVIF or WebP at the size they are shown, not as large JPEG or PNG files.umiarkowanaw przeglądarce
  • perf/large-imageAn image file in the source stays under the image budget (250 KB by default); larger ones are resized or re-encoded.umiarkowanastatyczne
  • perf/layout-shiftNothing moves after it appears - space is reserved for images, embeds, ads and late content (CLS 0.1 or less).umiarkowanaw przeglądarce
  • perf/lcp-imageThe LCP image is in the initial HTML, not lazy, and has fetchpriority="high"; a CSS background LCP image is preloaded.umiarkowanaw przeglądarce
  • perf/lcp-image-not-lazyThe image most likely to be the Largest Contentful Paint (hero, high priority) is never loading="lazy".umiarkowanastatyczne
  • perf/lcp-image-priorityThe image that is likely the LCP element loads eagerly with fetchpriority high; it is never lazy-loaded.poważnastatyczne
  • perf/lighthouse-ciLighthouse in CI runs each URL several times, asserts on metrics and categories with realistic thresholds, and never demands a perfect 100.drobnaręczne
  • perf/no-legacy-javascriptDo not ship polyfills and down-level transforms for features your target browsers already support; declare targets once.drobnaw przeglądarce
  • perf/no-whole-library-importClient code does not import all of lodash or moment; use lodash-es, per-method imports, Intl or the platform.umiarkowanastatyczne
  • perf/render-blocking-scriptA script in the head loads with defer, async or type="module", never as a plain blocking script.umiarkowanastatyczne
  • perf/srcset-sizesA srcset with width descriptors (400w, 800w) comes with a sizes attribute that matches the image's displayed width.umiarkowanastatyczne
  • perf/third-party-asyncThird-party scripts load with async or defer (or a framework strategy such as lazyOnload), never as parser-blocking tags.umiarkowanastatyczne
  • perf/third-party-costEach third-party script earns its place, loads late, and heavy embeds (video, maps, chat) start as a lightweight facade.umiarkowanaw przeglądarce
  • perf/yield-long-tasksMain-thread work over 50 ms is split and yields, and event handlers do the visible update first (INP 200 ms or less).umiarkowanaręczne

HTML 11 reguł

  • html/button-typeEvery button states its type (button, submit or reset); the default is submit.drobnastatyczne
  • html/constraint-attr-typeValidation attributes match the input type (pattern and maxlength on text-like types, min, max and step on number and date types).umiarkowanastatyczne
  • html/doctypeEvery HTML document starts with <!doctype html> so the browser renders it in standards mode.umiarkowanastatyczne
  • html/form-submitFields sit in a form that is handled on its submit event with a submit button, so Enter, autofill and native validation work.umiarkowanaręczne
  • html/icon-from-setWhen the project has an icon set (sprite, icon classes or an Icon component), markup uses it, never a hard-coded path to an icon file.drobnastatyczne
  • html/input-typeAn input for an email address, phone number or URL uses type email, tel or url, not text.drobnastatyczne
  • html/no-number-for-codesCodes made of digits (postal codes, card numbers, one-time codes, PINs) use type text with inputmode numeric, not type number.umiarkowanastatyczne
  • html/password-autocompletePassword fields say current-password (sign-in) or new-password (sign-up, change) in autocomplete, and never use autocomplete off.umiarkowanastatyczne
  • html/picture-imgEvery picture element ends with an img that has src, alt, width and height; source elements alone render nothing.poważnastatyczne
  • html/project-iconsIcons use the project's generated icon classes (its icon classes), not separate SVG image files.drobnastatyczne
  • html/required-select-placeholderA required single-choice select starts with an empty placeholder option (value=""), so the required check can fail.umiarkowanastatyczne

CSS 23 reguły

  • css/asset-urlIn a bundled project, url() to images and fonts is a relative path or alias the bundler resolves, not a hard-coded root or public/ path.drobnastatyczne
  • css/baseline-checkBefore using a newer CSS feature, check its Baseline status against the project's browser targets and plan the fallback.drobnaręczne
