I built a free, open-source tool that teaches AI coding agents to write better front-end 🛠️

⚡ One command in your project: npx github:dawidolko/frontend-skills init
🧭 It learns your stack, from React, Vue or Angular to a plain HTML site, and your own conventions
🤖 It installs only the skills that fit, for 17 coding agents, each in its own format: Claude Code, Codex, Cursor, Copilot, Gemini CLI and more
🔍 It audits your code with 275 rules, each with a stable id and a public source such as WCAG 2.2, MDN or web.dev
🩹 Every finding says what is wrong, in which file and line, why it matters and how to fix it
🪶 The skills stay short, so your agent spends few tokens on them

What I enjoyed most was deciding what not to promise. Automated checks find only part of the problems, so the report also lists what still needs a person.

It is free under the MIT licence. The full rule dictionary is at skills.dawidolko.pl and the code at github.com/dawidolko/frontend-skills 🚀
